🚀 Conhecendo o Snap!

🎭 Palco (Stage)

O palco é a área onde tudo acontece no projeto. É nele que os sprites aparecem, se movem e interagem.

  • Exibe animações e jogos.
  • Mostra cenários e fundos.
  • Recebe eventos e mensagens.
  • Permite interação com o usuário.

🧩 Sprites

Os sprites são personagens ou objetos do projeto.

  • Podem se mover.
  • Podem tocar sons.
  • Possuem scripts próprios.
  • Possuem fantasias próprias.
  • Podem enviar e receber mensagens.

🎨 Fantasias (Costumes)

Fantasias são diferentes aparências de um sprite.

  • Criar animações.
  • Mudar roupas ou aparência.
  • Representar diferentes estados.
  • Criar efeitos visuais.

⭐ Recursos Exclusivos do Snap!

  • ✅ Criação de blocos personalizados.
  • ✅ Recursão.
  • ✅ Listas dentro de listas.
  • ✅ Programação Funcional.
  • ✅ Procedimentos de primeira classe.
  • ✅ Hiperblocos (Hyperblocks).
  • ✅ Blocos como dados.

Blocos Funcionais

  • MAP - aplica uma função a todos os itens.
  • KEEP - filtra elementos.
  • COMBINE - reduz uma lista a um valor.
MAP [item × 2] EM [1,2,3,4]
Resultado: [2,4,6,8]

KEEP [item > 10] EM [5,12,20]
Resultado: [12,20]

🔷 C-Blocks (Blocos de Controle)

C-Blocks são blocos que possuem uma área interna para encaixar outros blocos.

  • Repetir
  • Sempre
  • Se
  • Se / Senão
  • Repita Até
  • Para Cada Item

Vantagens no Snap!

  • Receber funções como entrada.
  • Receber predicados personalizados.
  • Usar Rings (Anéis).
  • Criar C-Blocks personalizados.

🧠 Condições Complexas

O Snap! permite combinar várias condições lógicas. 

SE (
      (pontuação > 100 E vidas > 0)
      OU
      (fase = 10)
   )

Operadores Lógicos

  • E (AND) - todas as condições devem ser verdadeiras.
  • OU (OR) - pelo menos uma deve ser verdadeira.
  • NÃO (NOT) - inverte o resultado.
